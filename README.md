# ComfyUI Character Card Studio

![version](https://img.shields.io/badge/version-1.2.1-blue)

> Плагин ComfyUI для **Qwen-Image 2.1**: автоматическая генерация карт персонажа и сцены с несколькими ракурсами.
> Одно изображение персонажа или любой кадр сцены → автодополнение мультивидов / эмоций / деталей окружения → точная нарезка и вёрстка по макету.

![one-click](docs/oneclick_preview.png)

## Какую задачу решает

Собрать карту сеттинга вручную значит отдельно генерировать анфас, профиль, спину, портрет, позы, сетку эмоций и деталей, затем вклеивать каждую картинку в свою ячейку, выравнивать и не обрезать голову или ноги. Плагин сворачивает этот конвейер в ComfyUI:

```text
Одно референс-изображение персонажа  или  текстовый промпт
            ↓
   Qwen-Image 2.1 автоматически генерирует мультивиды / эмоции / детали
            ↓
   Автонарезка по выбранному макету (каждая ячейка 768×768)
            ↓
   Перестановка по panel_order, полный рост без обрезки → итоговая карта
```

## Ключевые возможности

- **Два входа**: загрузить референс как якорь идентичности или сгенерировать персонажа только из текста.
- **Узел «в один клик»**: макет, порядок, отображение в полный рост и размер вывода — в одном узле; узел нарезки без настроек.
- **Автонарезка и перестановка**: `panel_order` поддерживает записи вроде `1,3,2,4,5-9`; `fit_mode` по умолчанию «Полностью» — от макушки до подошв без обрезки.
- **8 макетов персонажа + 1 общий макет сцены**: от 4 до 14 ячеек — портрет+, два кадра, три вида, главный вид, эмоции, сеттинг и полный атлас; для сцены любое фото служит якорем для обзора 0°, 90°, 180°, 270°, панорамы 360° и детали окружения; редактор, направляющее изображение и сборка используют одни и те же данные раскладки.
- **Автозеркало правого профиля**: при сборке правый профиль отражается по горизонтали, чтобы левый и правый профили смотрели в разные стороны без опоры на инструкции модели.
- **Поассетная генерация + профессиональная вёрстка**: отдельно анфас / профиль / спина в полный рост, портрет, действия A/B, группа эмоций и деталей, затем авторазмещение по макету.
- **Стабильность вёрстки**: целая карта за один проход всё ещё зависит от случайности модели; для стабильных позиций и числа ячеек предпочтителен узел «3 Поячеечная генерация и вёрстка · готово».
- **Без лишних зависимостей**: только Pillow / NumPy / torch / aiohttp из ComfyUI.
- **Визуальный рабочий стол**: фронтенд в `web/` для редактирования состояния карты (HTTP-маршрут `/aicg3d/character-card/templates`).

## Узлы

| ID узла | Отображаемое имя | Назначение |
|---|---|---|
| `AICG3D_CharacterCardOneClick` | Промпт карты персонажа/сцены в один клик · Qwen Image 2.1 | Выбор макета, описание персонажа → промпт + негатив + пустое направляющее изображение + JSON карты |
| `AICG3D_CharacterSheetSplitter` | Автонарезка карты персонажа/сцены · без настроек | Читает конфиг первого узла, нарезает, показывает полный рост, переставляет |
| `AICG3D_CharacterCardStudio` | Рабочий стол карты персонажа/сцены · Qwen Image 2.1 | Продвинутый режим: ручная замена ассетов по ячейкам и подгонка кадрирования |
| `AICG3D_CharacterCardAssetPrompt` | Промпты ассетов карты персонажа · Qwen Image 2.1 | Отдельные промпты для полного роста / портрета / действий / эмоций / деталей |
| `AICG3D_CharacterCardAssetComposer` | Профессиональная вёрстка карты · авторазмещение | Собирает независимые ассеты в итоговую карту по макету |
| `AICG3D_CardSettingsFive` | 1 Настройка типа карты персонажа/сцены · 9 макетов | Первый шаг линейного пайплайна (ID узла сохранён для старых workflow) |
| `AICG3D_Qwen21ModelLoader` | 2 Выбор модели Qwen Image 2.1 | Выбор UNET / CLIP / VAE → MODEL/CLIP/VAE |
| `AICG3D_CharacterCardGeneratorSingle` | 3 Поячеечная генерация и вёрстка · готово | Каждая включённая ячейка генерируется отдельно и точно вставляется по координатам шаблона |

## Быстрый старт

Основной вариант: откройте `workflows/карта_персонажа_9_макетов_линейный.json`.

- **Карта из изображения**: `workflows/карта_в_один_клик_QwenImage21.json` — загрузите референс в `LoadImage`, в узле промпта выберите макет и дополните описание, поставьте в очередь.
- **Карта из текста**: `workflows/карта_в_один_клик_промпт_QwenImage21.json` — заполните `character_prompt`.
- **Линейный текстовый пайплайн**: `workflows/карта_персонажа_9_макетов_текст_линейный.json`.
- **Базовая карта / ассеты**: также доступны `workflows/карта_персонажа_QwenImage21.json`, `workflows/карта_ассеты_QwenImage21.json`, `workflows/карта_ассеты_промпт_QwenImage21.json`.
- **Дорисовка ракурсов сцены**: выберите `scene_six_view`, подключите любое фото сцены к `reference_image`; первая ячейка сохраняет фронтальный оригинал, остальные пять — 90°, 180°, 270°, плюс панорама 360° и деталь окружения.

## Установка

Положите всю папку в:

```text
ComfyUI/custom_nodes/ComfyUI-CharacterCardStudio
```

Перезапустите ComfyUI.

## Рекомендуемые файлы моделей

Значения по умолчанию в workflow (если имена на диске другие — перевыберите в загрузчике):

- UNET: `qwen_image_2.1_bf16.safetensors` (при нехватке VRAM — `qwen_image_2.1_int8_convrot.safetensors`)
- CLIP: `qwen3vl_8b_int8_convrot.safetensors`, тип `qwen_image`
- VAE: `qwen_image_2.1_vae_bf16.safetensors`
- Энкодер: `TextEncodeQwenImage21`
